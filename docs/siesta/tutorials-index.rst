Tutorial Index
==============

Interactive tutorials for atomate2siesta. All tutorials include working code examples
and can be run in three modes: dry-run (preview), local execution, or HPC submission.

.. note::
   **New to atomate2siesta?** Start with :doc:`tutorials-auto/01-basics`
   and the relaxation tutorial.

.. tip::
   Generate tutorial scripts automatically with the CLI:

   .. code-block:: bash

      # Interactive mode (zero memorization!)
      atomate2siesta-maker --interactive

      # Or direct generation
      atomate2siesta-maker relax structure.cif
